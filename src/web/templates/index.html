1. 共通項限定 vs 稠密(Dense)埋め込み

2007年の手法（ピアソン/共通項cos）は、評価アイテムが1つでも完全に一致すると類似度1.0になり誤爆しやすい（スパースの罠）。2026年のEmbeddingはプロフィール全文の意味空間を捉えるため、語彙が違っても高精度に同セグメントを捉えます。

2. スケールとインデックス（O(N²) vs ANN）

2007年のメモリ総当たりは1万件で数十〜数百msに達し、数万件で破綻します。BigQueryのTreeAH / IVFインデックスは1000万件規模でも数ミリ秒〜数十ミリ秒で近傍を探索可能です。

3. BigQuery インデックスの最小行数

BigQuery の CREATE VECTOR INDEX は 5,000行以上のテーブルでのみ有効化されます。数千行以下の小規模データセットでは自動的にブルートフォース（厳密探索）が実行されます。
